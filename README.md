# تدريب لامتحان السواقة في الأردن

موقع تفاعلي (React + Vite) للاستعداد للفحص النظري لرخصة القيادة، يركّز على **الفهم** لا الحفظ. يغطي ثلاث فئات تختارها من الصفحة الرئيسية:

| المسار | الأجزاء |
| --- | --- |
| **الفئتان الثالثة والرابعة** (السيارات) | 9 أجزاء: الشواخص، الأمان والإسعاف، فئات الرخص والعلامات الأرضية، الوقوف والأحكام العامة، الميكانيك، الأولويات، مواقف تطبيقية، **قواعد السير الرسمية**، **القانون: التعريفات والمخالفات والعقوبات** |
| **الفئتان الخامسة والسادسة** (الشاحنات والحافلات) | 4 أجزاء: المركبات الثقيلة، الحمولة والأوزان، القيادة الآمنة، **القانون والنظام للمركبات الثقيلة والحافلات** + أساسيات مشتركة |
| **الدراجة النارية** (الفئة الأولى) | 4 أجزاء: الرخصة والخوذة والجاهزية، التحكم والفرملة، القيادة بين السيارات، **القانون والنظام للدراجات** + أساسيات مشتركة |

الأساسيات المشتركة (الشواخص، الأولويات، الوقوف والأحكام العامة، وجزءا القانون) تُضاف إلى الاختبار الشامل لكل فئة: ثلثا أسئلته من أجزاء الفئة نفسها والباقي من المشترك.

## التوثيق بالمصادر الرسمية

الأجزاء المسماة «من نص النظام» و«القانون» مبنية على النصوص المنشورة، ولكل سؤال فيها حقل `source` برقم المادة يظهر مع الشرح:

- **قانون السير رقم 49 لسنة 2008** (المعدّل حتى قانون 18 لسنة 2023)
- **نظام قواعد السير والمرور على الطرق لسنة 2004**
- **نظام ترخيص السواقين لسنة 2008**

الروابط في صفحة «المصادر والتوثيق» داخل الموقع. كتاب الفحص النظري الرسمي نفسه لم أجده منشوراً كملف، فاعتمدنا على الأنظمة التي يقوم عليها. السرعات القصوى مُحالة في القانون إلى تعليمات لم أعثر على نصها، فلم تُدرَج أرقامها.
- كل درس: شرح مبسّط + جداول + رسومات (شواخص وعلامات ومخططات تقاطعات مرسومة بـ SVG) + مربع «لماذا؟» + سؤالان لاختبار الفهم مع تفسير فوري.
- أدوات تفاعلية: حاسبة مسافة التوقف (للسيارة والمركبة الثقيلة)، ومحرك رباعي الأشواط متحرك، وخريطة النقاط العمياء حول الشاحنة.
- **شرح مبسّط لدرس الميكانيك** بأساليب متعددة، وبنفس القوالب يمكن تطبيقها على أي درس صعب (عناصر `simple` و`analogy` و`glossary` و`flow` و`recap` و`match` وأدوات `carparts` و`truckparts` و`airgauge` و`dashboard` كما في `mechanics.js` و`heavy-vehicles.js`):
  - **«بكلام بسيط»** في بداية كل درس، و**«الخلاصة بجملة واحدة»** في نهايته.
  - **تشبيهات من الحياة** (جسم الإنسان، بطارية الهاتف، غيارات الدراجة، قدر الضغط، البالون).
  - **قاموس الكلمات الصعبة** بالاسم الدارج والمعنى البسيط والشبيه.
  - **قصص خطوة بخطوة** (رحلة الوقود، ماء التبريد، الزيت، الفرامل).
  - **رسم سيارة من الداخل** تضغط على أجزائه، و**لوحة عدادات** تضغط على لمباتها لتعرف ماذا تفعل.
  - **ألعاب توصيل** (وصّل الكلمة بمعناها)، وأسئلة مواقف بلغة بسيطة.
  - **دروس المركبات الثقيلة** مبسّطة بالأسلوب نفسه: رسم قاطرة ومقطورة تضغط على أجزائه، وجهاز **ضغط الهواء** تحرّك مؤشره لترى متى يرنّ الإنذار ومتى تنطبق الفرامل النابضية، وتشبيهات (نفّاخ، زنبرك، عربة تسوّق) وقاموس مصطلحات.
- **قراءة صوتية بالعربية**: زر «🔊 استمع للدرس» يقرأ الدرس كاملاً ويظلّل الفقرة التي تُقرأ، وزر لقراءة كل سؤال وخياراته، وزر «اقرأ الشرح» بعد الإجابة، وخيار قراءة الشرح تلقائياً، وتحكم بالسرعة. تفضّل الصوت **السعودي** تلقائياً، ويمكنك اختيار صوت آخر وتجربته من «إعدادات الصوت». تعتمد على أصوات جهازك:
  - **أسهل حل**: افتح الموقع في **Microsoft Edge**؛ فيه أصوات سعودية طبيعية (حامد وزارية) عند الاتصال بالإنترنت، دون تثبيت.
  - **للعمل دون إنترنت على ويندوز**: شغّل `install-saudi-voice.bat` (يطلب موافقتك كمسؤول ويثبّت صوت «العربية (السعودية)» من مميزات ويندوز الاختيارية) ثم أعد تشغيل المتصفح.
- **مؤشر جاهزية** يجمع إتقانك الفعلي للأسئلة ونتائج آخر اختباراتك الشاملة، ويُظهر أضعف أجزائك.
- **مراجعة اليوم** بالتكرار المتباعد (خمسة صناديق: يوم، 3 أيام، أسبوع، أسبوعان، شهر): الخطأ يعود فوراً، والصواب يتباعد.
- **اختبار تشخيصي** في البداية، وتدريب لكل جزء، وتدريب مختلط، ومراجعة الأخطاء، مع تفصيل نتيجتك بحسب الجزء.
- **نسخة احتياطية**: تنزيل تقدّمك واستعادته على جهاز آخر.
- اختبار تجريبي شامل: 60 سؤالاً، 60 دقيقة، النجاح بـ 51، مع تفصيل الأداء لكل جزء.
- قاموس الشواخص مع وضع «اختبر نفسك».
- تقدّمك يُحفظ في المتصفح (localStorage) ولا يخرج من جهازك. يعمل بدون إنترنت بعد التثبيت.

## التشغيل محلياً

يلزمك [Node.js](https://nodejs.org) (الإصدار 18 أو أحدث).

على ويندوز: اضغط مرتين على `start.bat`.

**للتثبيت على الهاتف أو الحاسوب والعمل بدون إنترنت (PWA):** شغّل `install-app.bat` (أو `npm run serve`) وافتح http://localhost:4173 في Chrome أو Edge ثم اختر «تثبيت التطبيق». بعد أول زيارة يعمل الموقع دون اتصال. وللنشر المجاني على الإنترنت مع الـ SEO (Cloudflare Pages أو Netlify أو GitHub Pages) اتبع **[DEPLOY.md](DEPLOY.md)**؛ وأهم خطوة قبل النشر أن تكتب عنوان موقعك في `src/site.config.js`.

أو من الطرفية:

```bash
npm install
npm run dev
```

ثم افتح http://localhost:5180

لإنتاج نسخة جاهزة للنشر: `npm run build` (الناتج في مجلد `dist`، ويمكن معاينته بـ `npm run preview` على http://localhost:4173). يولّد البناء صفحة HTML ثابتة لكل رابط مع وسوم الـ SEO و`sitemap.xml` و`robots.txt` و`404.html`. وللعمل أثناء التطوير فقط يكفي `npm run dev` (دون صفحات ثابتة)، و`npm run build:spa` لبناء بسيط بلا توليد صفحات.

الروابط الآن مسارات حقيقية (`/topic/signs/` و`/questions/signs/` و`/track/heavy/`...) وليست `#/...`، والروابط القديمة بالعلامة `#/` تُحوَّل تلقائياً. لذلك يجب أن تخدم الاستضافة ملف `404.html` للمسارات غير الموجودة (كل المنصات المذكورة في DEPLOY.md تفعل ذلك).

## هيكل المشروع

```
src/
  data/
    topics/*.js      ← محتوى كل جزء (الدروس والأسئلة)  ← هنا تعدّل وتضيف
    helpers.js       ← mcq() و tf() لكتابة الأسئلة بسرعة
    index.js         ← تجميع الأجزاء + المسارات TRACKS (أي أجزاء لكل فئة) + إعدادات الاختبار EXAM
  components/
    Signs.jsx        ← مكتبة الشواخص والإشارة الضوئية والعلامات الأرضية (SVG)
    Intersection.jsx ← مخطط التقاطع والدوّار
    widgets.jsx      ← حاسبة المسافة + المحرك
    Blocks.jsx       ← مُصيّر عناصر الدرس
    QuestionView.jsx, Quiz.jsx, Exam.jsx, TopicPage.jsx, Home.jsx, SignsLibrary.jsx
  store.jsx          ← حفظ التقدم
  styles.css         ← التصميم (فاتح/داكن تلقائياً)
  site.config.js     ← إعدادات النشر والـ SEO (عنوان الموقع، التواصل، الإحصاءات، رموز التحقق)
  seo.js             ← عنوان ووصف وcanonical وبيانات منظمة (JSON-LD) لكل صفحة + قائمة المسارات
  router.jsx         ← توجيه بمسارات حقيقية (History API)
  entry-server.jsx   ← مدخل البناء الثابت (SSR) المستخدم في scripts/prerender.mjs
  components/QuestionBank.jsx ← صفحة «كل الأسئلة مع الإجابات» لكل جزء (قابلة للفهرسة والطباعة)
scripts/
  prerender.mjs      ← يولّد الصفحات الثابتة وsitemap.xml وrobots.txt و404.html
  make-og-image.ps1  ← يرسم صورة المشاركة public/og-image.jpg (ويندوز)
  check-data.mjs     ← فحص سلامة الأسئلة والمصادر (npm run check)
```

## إضافة أو تعديل الأسئلة

افتح ملف الجزء المطلوب في `src/data/topics/` وأضف في مصفوفة `questions`:

```js
mcq('نص السؤال؟', ['خيار أ', 'خيار ب', 'خيار ج', 'خيار د'], 0 /* فهرس الجواب الصحيح */, 'الشرح الذي يظهر بعد الإجابة', {
  sign: 'stop',          // اختياري: يعرض شاخصة (انظر مفاتيح SIGN_DEFS في Signs.jsx)
  ref: 'regulatory',     // اختياري: رقم الدرس الذي يرتبط به زر «راجع الدرس»
})

tf('عبارة صحيحة أم خاطئة؟', true, 'الشرح')
```

بعد أي تعديل شغّل `npm run check`: يتأكد أن فهرس الجواب صحيح، وأن الشواخص والروابط موجودة، وأن بنك كل فئة يكفي لاختبار 60 سؤالاً.

لإضافة جزء جديد: أنشئ ملفاً في `src/data/topics/` بنفس بنية الملفات الموجودة، واستورده في `src/data/index.js` وأضف رقمه في `topics` للمسار المناسب داخل `TRACKS`.

يمكن أيضاً إرفاق `marking: 'solid'` أو `diagram: {...}` (مخطط تقاطع) كما في ملف `priority.js`.

## ملاحظات مهمة

- المحتوى والأسئلة **مكتوبة أصلياً** لهذا المشروع ولم تُنسخ من موقع trainingdriving.com؛ استُخدم الموقع فقط كمرجع لتقسيم الأجزاء ومواصفات الاختبار.
- فئات الرخص وشروطها وتصريح القيادة السنوي مأخوذة من **نظام ترخيص السواقين لسنة 2008** وقد عُدّل لاحقاً.
- الغرامات المذكورة منقولة من نص قانون السير المنشور حتى تعديل 2023، وقد ظهرت أخبار عن تعديل لاحق؛ تحقق من النص الحالي قبل الاعتماد على الرقم.
- بين النظام (م35: 15 متراً من التقاطع) والقانون (م37: 20 متراً في الغرامة) اختلاف في مسافة الوقوف من التقاطع، وقد نبّه عليه الدرس.
- أرقام حاسبة مسافة التوقف تقريبية للتعلّم، وأرقام الشواخص (3.5m، 5.5t، 10%) للتوضيح فقط.
- لم تُدرج أرقام السرعات والغرامات الأردنية لأن المصادر غير الرسمية متضاربة. أضِفها بعد التحقق من النص الرسمي لقانون السير.
- قاعدة «الأفضلية للقادم من اليمين»، وأرقام الطوارئ، وتفاصيل الوقوف: راجعها مع دليل دائرة ترخيص السواقين والمركبات قبل الامتحان.
